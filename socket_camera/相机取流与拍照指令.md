# 相机取流与拍照指令

以下指令基于 `socket_camera/hikrobot_stream.py`。脚本当前默认相机 IP 为 `192.168.34.55`。在本仓库根目录打开 PowerShell 后执行。这是海康 GigE SDK 取流路径；本机 TCP 服务触发路径见同目录 `README.md`。

## 准备

安装脚本依赖，并确保计算机能发现相机、相机未被其他程序独占：

```powershell
python -m pip install -r .\socket_camera\requirements-camera.txt
```

## 实时取流预览

先查看相机当前曝光时间、增益和各自允许范围：

```powershell
python .\socket_camera\hikrobot_stream.py --show-settings
```

使用相机当前设置预览：

```powershell
python .\socket_camera\hikrobot_stream.py
```

画面过暗时，可使用已在当前相机上验证的参数：曝光时间 `100000` 微秒（100 毫秒）、增益 `12`。

```powershell
python .\socket_camera\hikrobot_stream.py --exposure-us 100000 --gain 12
```

预览窗口中按 `S` 拍照，照片保存为当前工作目录下的 `camera_192.168.34.55.jpg`；按 `Q` 或 `Esc` 退出。鼠标滚轮可缩放，中键可恢复默认缩放。

## 拍照并保存一帧

```powershell
python .\socket_camera\hikrobot_stream.py --output .\camera_192.168.34.55.jpg
```

使用同样的相机曝光和增益拍照：

```powershell
python .\socket_camera\hikrobot_stream.py --exposure-us 100000 --gain 12 --output .\camera_192.168.34.55.jpg
```

脚本取得一帧后保存到指定路径并退出，不打开预览窗口。`--output` 可改为其他已有目录中的文件路径，例如 `D:\photos\shot.jpg`。

## 可选参数

`--exposure-us` 设置相机曝光时间，单位为微秒；`--gain` 设置相机增益。传入其中一个参数时，脚本会关闭对应的自动模式，再设置该值。两者的可用范围以 `--show-settings` 显示的相机实际范围为准；超出范围会报错。曝光时间越长，画面通常越亮，但运动模糊和帧间隔也可能增加；增益越高，噪声也可能越明显。需要更高帧率时，可适当缩短曝光时间并结合现场照明调整。

`--brightness` 仍可选，用于对取到的图像做像素亮度偏移，范围 `-255` 到 `255`，默认 `0`。它不替代相机曝光或增益调整。

`--timeout` 控制等待单帧的超时时间，单位为毫秒，默认 `3000`。例如将其设为 5 秒：

```powershell
python .\socket_camera\hikrobot_stream.py --timeout 5000
```

## 当前相机实测

在同一场景下，原设置曝光 `15000` 微秒、增益 `0` 的样张平均灰度约 `3.8`；曝光 `100000` 微秒、增益设为 `12`（相机回读约 `11.9906`）后，平均灰度约 `105.2`。可对比[原设置样张](camera_before_exposure_gain.jpg)与[调整后样张](camera_exposure_100000_gain_12.jpg)。相机当前值可以随时用 `--show-settings` 查询。
